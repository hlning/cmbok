## 一、软件简介

Cmbok 是一款「一站式」漫画/图书获取与管理工具，把分散在多个站点的资源检索、下载、格式转换、本地书库管理整合为一个流畅的桌面应用，专注内容本身。

### 核心能力一览

| 模块 | 能力 | 
| --- | --- | 
| 📚 漫画搜索 | 漫画检索、章节选择、批量下载（EPUB / PDF / MOBI） | 
| 📖 图书搜索 | 图书检索、流式下载（EPUB/PDF/MOBI 等） |
| 🌐 漫画网站 | 多站点漫画解析下载、自定义站点配置 | 
| 📁 文件管理 | 浏览/复制/剪切/粘贴/删除/拖拽 | 
| ⭐ 收藏管理 | 漫画/图书收藏、文件夹分类 | 
| ⬇️ 下载管理 | 任务进度、状态、右键操作 | 
| 🛠️ 工具箱 | PDF/EPUB/DOC 互转、合并 PDF | 
| 🎮 Komga | 内置媒体服务器，Kindle 在线阅读 | 


## 二、快速上手

只需四步，开启你的漫画/图书之旅：

1. **搜索** -> 在「漫画」或「图书」界面输入名称搜索。
2. **选择** -> 在结果卡片上点击「获取章节」（漫画）或「下载」（图书）。
3. **查看进度** -> 切换到「下载」界面，实时查看下载进度。
4. **阅读** -> 下载完成后，在「文件管理」找到文件，或启动 Komga 在 Kindle 上在线阅读。


## 三、功能详解

### 3.1 漫画搜索与下载

提供海量漫画检索与章节下载。

**操作步骤：**

1. 在顶部搜索框输入漫画名，回车搜索。
2. 结果以卡片形式展示（封面、名称、作者），支持分页（每页 9 / 27 条）。
3. 卡片右侧两个按钮：
   - ⭐ **收藏**：加入收藏夹（见 3.5）。
   - 📤 **获取章节**：加载章节列表，选择章节后开始下载。
4. 下载产物默认为 **EPUB**，可在设置中开启同步生成 **PDF** 与 **MOBI**（MOBI 需配置 Calibre）。

**下载说明：**

- 下载目录：`下载目录/漫画名/章节名/`，图片打包为 EPUB。
- 并发受「下载最大线程」设置约束，避免触发风控。

### 3.2 图书搜索与下载

支持两种模式：

| 模式 | 登录要求 | 每日额度 | 适用场景 |
| --- | --- | --- | --- |
| 内置账号 | 无需登录 | 5 本/日 | 快速体验、匿名使用 |
| 自有账号 | 邮箱密码登录 | 10 本/日（每账号独立） | 长期使用、更高额度 |

**操作步骤：**

1. 在搜索框输入书名，可按年份/语言/格式精确筛选。
2. 结果卡片展示封面、书名、作者、年份/语言/格式/大小。
3. 卡片右侧按钮：
   - ⭐ **收藏**
   - ⬇️ **下载**：流式下载，实时进度。
4. 下载文件保存到下载目录，文件名格式：`书名_编号.格式`。

**登录方式：**

- 点击左下角头像 -> 弹出登录框 -> 输入邮箱密码（或注册）。
- 登录成功后，头像显示**用户名**与当日下载额度（如 `5/10`）。
- 内置账号模式下头像显示「未登录 / 当日下载：X/5」。
- 退出登录后自动切回内置账号额度显示。

> ℹ️ **额度说明**：每个登录账号独立计算 10 本/日额度，互不影响；内置账号全局共享 5 本/日，跨日自动重置。

### 3.3 漫画网站

内置 4 个漫画站点（来漫画、再漫画、咚漫、MYCOMIC），并支持自定义站点配置。

**操作步骤：**

1. 切换到「网站」界面，自动加载站点列表。
2. 卡片展示站点名、图标，右侧按钮：
   - ✏️ **编辑**：修改站点配置（CSS 选择器等）。
   - 🗑️ **删除**
3. 点击「新增站点」填写站点配置。
4. 点击站点卡片进入，搜索并下载漫画。

**自定义站点配置项：**

| 字段                 | 说明                  | 必填 |
| ------------------ | ------------------- | -- |
| name               | 站点名称                | ✅  |
| url                | 站点地址                | ✅  |
| comic\_name\_dom   | 漫画名称选择器             | ✅  |
| chapter\_name\_dom | 章节名称选择器             | ✅  |
| chapter\_link\_dom | 章节链接选择器             | ✅  |
| comic\_cover\_dom  | 漫画封面选择器             | 可选 |
| img\_dom           | 图片选择器（留空取全部 img）    | 可选 |
| img\_attr          | 图片懒加载属性（如 data-src） | 可选 |
| use\_frame         | 是否用 iframe 加载（1/0）  | 可选 |

> ℹ️ 普通站点走直连解析；需要 JS 渲染的站点可启用 iframe 模式。

3. 面包屑导航切换文件夹层级（首页/子文件夹）。
4. 卡片操作：

   - 图书：下载、取消收藏。
   - 文件夹：删除文件夹。

### 3.8 Komga 媒体服务器

内置 Komga（开源媒体服务器），无需单独安装 Java。

**功能：**

- 软件启动时自动启动 Komga（可在设置关闭）。
- 监听本地 25600 端口。
- 点击导航栏「Komga」直接打开 Web 控制台（`http://127.0.0.1:25600/`）。
- 在 Komga 中将下载目录配置为媒体库，即可在 Kindle 浏览器中在线阅读。

**设置选项：**

- 启动时是否运行 Komga（默认开）。
- Komga 是否保留后台（软件退出后仍运行，便于 Kindle 持续访问）。

> ℹ️ **Kindle 在线阅读**：Kindle 连接同一局域网 Wi-Fi，在浏览器访问 `http://电脑IP:25600`，即可浏览/阅读已入库的漫画与图书。

## 五、账号与下载额度

### 5.1 额度规则

| 场景          | 每日额度      | 计数方式       |
| ----------- | --------- | ---------- |
| 内置账号模式（未登录） | 5 本/日     | 全局共享，跨日重置  |

### 5.2 头像显示

导航栏左下角头像实时显示当前状态：

- **未登录**：`未登录` + `当日下载：X/5`
- **已登录**：`用户名` + `当日下载：X/10`

下载完成或退出登录后自动刷新计数。

### 5.3 达到额度

下载到额度上限时会弹框提示「今日下载已达 N 本上限，请明天再试」，并拦截本次下载。额度每日自动重置。

## 六、常见问题（FAQ）

**Q2：图书下载提示「今日无法下载」？**
A：服务端限制，请明天再试，或切换账号/使用自有账号。

**Q3：内置账号提示「今日已达 5 本上限」？**
A：内置账号全局每日 5 本，次日自动重置；或关闭内置账号模式，登录自有账号（每日 10 本）。

**Q4：转换 MOBI 失败？**
A：MOBI 转换依赖 Calibre 的 `ebook-convert.exe`，请在设置中正确配置路径。

**Q5：Komga 启动失败/打不开？**
A：检查 25600 端口是否被占用，或确认 Komga 设置已开启。
